# Process Algebra Grammar

> Status: waiting for the official course grammar.

The implementation must use the official supplied grammar rather than inventing a simplified replacement.

Before parser implementation begins, record:

- All lexical tokens and identifier rules
- Grammar productions
- Operator precedence and associativity
- SD-, SMD-, and AD-specific constructs
- Continuation semantics
- Reference and recursive-reference rules
- Whitespace and comment rules
- Valid examples and invalid counterexamples

Any uncertain rule should be raised as a group question and resolved before implementation.
